Featured Projects

MRI-Based Machine Learning for FCD Type II Classification

Studied whether measurements from brain MRI scans can help tell FCD Type II cases apart from healthy controls. Used 167 subjects and 631 MRI features, and tested Logistic Regression and ExtraTrees with nested 5-fold cross-validation. Logistic Regression reached 70.06% accuracy, while ExtraTrees reached a 0.7676 ROC-AUC. These are early research results, not a medical diagnostic tool.
